# Xian Haoran — Data Science Portfolio

This repository contains the GitHub Pages entry file for my data science portfolio. The website presents my skills and a reproducible project on Hong Kong fertility trends from 1991 to 2021.

It also includes [CISC7204 Assignment 02 data visualization coursework](cisc7204-Assgn02-2026-mc642513/), covering Jupyter notebooks, Plotly and Dash projects, supporting data, and screenshots.

To publish it, configure GitHub Pages under **Settings → Pages** with **Deploy from a branch**, branch `main`, folder `/ (root)`.
